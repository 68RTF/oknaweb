# INSIDE HOME

Сайт мебельного проекта INSIDE HOME. Страница с галереей, формой заявки и отзывами находится в `index.html`. Код сайта — в `app.js` и `styles.css`; для отправки заявок предусмотрена функция Netlify в `netlify/functions/leads.ts` и таблица в базе данных.

## Развёртывание

Настройки Netlify находятся в `netlify.toml`. Сайт использует функцию `/api/leads` для сохранения заявок; одна только публикация статических файлов не обеспечит работу формы. Доступность базы данных и формы на конкретном развёртывании нужно проверять отдельно.

Страница `admin.html` показывает будущий интерфейс ролей. Авторизация и серверное управление правами пока не реализованы; эта страница не выдаёт доступ к заявкам.

У репозитория пока нет лицензии на повторное использование кода.
